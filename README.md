# Futuristic Enterprise Analytics Dashboard

A modern, cutting-edge enterprise analytics dashboard built with React, TypeScript, Vite, and Tailwind CSS. Features interactive data visualizations, AI insights, and comprehensive analytics capabilities.

## Features

- 📊 **Interactive Analytics**: Real-time data visualization with Recharts
- 🤖 **AI Insights**: Machine learning-powered data analysis
- 👥 **User Management**: Complete user administration system
- 📈 **Reports**: Comprehensive reporting capabilities
- 🎨 **Modern UI**: Beautiful, responsive design with Tailwind CSS
- ⚡ **High Performance**: Built with Vite for lightning-fast builds
- 🔐 **Authentication**: Secure login and registration system
- 🏗️ **Enterprise Ready**: Scalable architecture for enterprise use

## Tech Stack

- **Frontend Framework**: React 19.2.3 with TypeScript
- **Build Tool**: Vite 7.3.2
- **Styling**: Tailwind CSS 4.1.17
- **Visualization**: Recharts 3.8.1
- **Animation**: Framer Motion 12.38.0
- **Icons**: Lucide React 1.14.0

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/MUNNAMOMIN369/futuristic-enterprise-analytics-dashboard.git
cd futuristic-enterprise-analytics-dashboard
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The optimized production build will be created in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```

## Project Structure

src/

## Deployment

This project is configured for seamless deployment on **Vercel**. See [DEPLOYMENT.md](./DEPLOYMENT.md) for detailed instructions.

### Quick Deploy to Vercel

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Vercel will automatically detect this is a Vite project
4. Your site will be live in minutes!

## Environment Variables

Create a `.env.local` file based on `.env.example`:

```bash
cp .env.example .env.local
```

Configure your environment variables as needed.
